\## 1. Instrucciones de Instalación y Pruebas



1\. Clona o copia este repositorio dentro de la carpeta de `addons` de tu instancia de Odoo 17.

2\. Inicia tu servidor Odoo activando el modo desarrollador.

3\. Actualiza la lista de aplicaciones en el menú de Aplicaciones.

4\. Busca el módulo \*\*Container Demurrage Control\*\* y haz clic en \*\*Instalar\*\*.

5\. Para ejecutar las pruebas automatizadas (unit tests) por consola, arranca el servidor con:

&#x20;  ```bash

&#x20;  python odoo-bin -d nombre\_base\_datos -i container\_demurrage\_control --test-enable --stop-after-init
